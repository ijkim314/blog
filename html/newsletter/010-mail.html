부모 찾기와 상태 반영은 :has()

SCROLL-DRIVEN ANIMATION · 지원 확인

SCROLL-STATE QUERY · 지원 확인

sticky 상태와 스냅 위치 감지하기

IntersectionObserver나 스크롤 위치 비교 없이 붙어 있는 헤더와 스냅된 항목을 선택합니다. 캐러셀의 현재 카드나 고정 헤더의 그림자를 CSS만으로 표현할 수 있습니다.
@STARTING-STYLE · BASELINE 2024

display: none도 자연스럽게 전환하기

@starting-style과 transition-behavior: allow-discrete를 조합해 팝오버와 dialog의 등장·퇴장 효과를 만듭니다. 애니메이션용 클래스를 넣고 빼는 코드를 줄여 줍니다.
INTERPOLATE-SIZE · 지원 확인

height: auto 전환도 CSS로

콘텐츠 높이를 측정해 픽셀 값으로 넣는 대신 interpolate-size: allow-keywords 또는 calc-size()로 auto 크기를 전환합니다. 아코디언과 펼침 패널에 활용해 보세요.
CSS CAROUSEL · CHROME 135+

버튼과 인디케이터가 있는 CSS 캐러셀

SVG 도구, 만드는 것부터 화면에 적용하기까지

이번에는 SVG 작업에 활용할 수 있는 도구와 자료를 소개하려고 합니다. SVG는 아이콘이나 로고에 자주 사용하는 이미지 형식이지만, 글자가 타이핑되거나 손으로 그린 선이 움직이는 효과도 표현할 수 있습니다. 작은 기능 하나를 편리하게 만들어 공개한 도구들을 보면, 평소 직접 구현하기에는 조금 번거로웠던 작업을 줄이는 데 도움이 되겠다는 생각이 듭니다.

텍스트를 입력하면 타이핑 애니메이션으로

TypingSVG는 텍스트와 옵션을 입력하면 타이핑 애니메이션이 들어간 SVG를 만들어 주는 도구입니다. 여러 줄의 문장, 커서 모양, 글자가 지워지는 속도 등을 조절할 수 있어 소개 문구에 움직임을 더할 때 참고하기 좋습니다.

이렇게 SVG 자체에 포함된 애니메이션은 웹페이지에서 <img>로 불러와도 표현할 수 있습니다. 타이핑 효과를 위해 페이지에 별도의 스크립트를 작성하지 않아도 된다는 점이 편리합니다. 다만 외부 생성 주소를 그대로 사용할지, 파일로 저장해 프로젝트에서 관리할지는 구분해서 생각해야 합니다.

손으로 그린 선과 낙서를 화면의 요소로

Strokes는 직접 그린 선을 애니메이션으로 바꿔 주는 도구입니다. 서명이나 손글씨가 그려지는 듯한 효과를 떠올리면 이해하기 쉽습니다. 소개된 애니메이션 출력 방식은 React와 Motion을 사용하는 컴포넌트이므로, SVG 파일 하나를 넣는 방식과는 준비 과정이 다릅니다.

React와 Motion을 이미 사용하는 프로젝트라면 활용하기 수월하겠지만, 간단한 HTML 화면이라면 이 효과 하나를 위해 필요한 라이브러리가 늘어날 수 있습니다. 도구를 고를 때는 미리보기뿐 아니라 결과물이 어떤 형식으로 제공되고, 우리 프로젝트에서 어떻게 동작하는지도 함께 확인해야 한다고 생각합니다.

직접 그리는 대신 준비된 요소를 활용하고 싶다면 SVG Doodles도 살펴볼 만합니다. 손으로 그린 느낌의 SVG를 골라 디자인에 활용할 수 있는 모음입니다. 화면에 작은 포인트를 더할 때 유용하겠지만, 기존 아이콘이나 글꼴과 자연스럽게 어울리는지도 함께 보는 것이 좋겠습니다.

같은 SVG라도 넣는 방식에 따라 달라집니다

SVG는 이미지 파일로 불러올 수도 있고, HTML 안에 코드를 직접 넣거나 CSS의 background-image에 데이터 URL로 넣을 수도 있습니다. CSS에 넣을 때는 SVG 문자열의 일부 문자를 URL 인코딩해야 합니다. 예를 들어 색상 값에 사용하는 #은 %23으로 바꾸는 식입니다. 작은 장식에는 편리하지만 코드가 길어지면 읽고 수정하기 어려워질 수 있습니다.

적용 방식을 정할 때는 이미지의 역할도 함께 생각해야 합니다. 의미를 전달하는 이미지라면 대체 텍스트를 제공하고, 단순한 배경 장식이라면 본문을 읽는 데 방해가 되지 않도록 구성하는 식입니다. 관련 내용은 David Bushell의 SVG 최적화와 접근성 기초를 참고해 보세요. CSS로 도형을 표현하는 방법이 궁금하다면 함께 소개된 shape() 가이드도 이어서 읽어볼 만합니다.

반복해서 사용하는 SVG를 관리하는 방법

같은 아이콘을 여러 곳에 넣는다면 SVG의 <use> 요소를 활용하는 방법도 있습니다. 도형을 정의해 두고 필요한 위치에서 참조하는 방식입니다. 다만 스타일을 전달하는 방법이나 외부 파일을 불러오는 조건에는 제약이 있어, 프로젝트에 맞는 구조인지 살펴봐야 합니다.

Fotis Papadogeorgopoulos의 @svg-use는 이와 관련해 살펴볼 수 있는 JavaScript 기반 도구입니다. 도입을 검토한다면 필요한 스타일 변경이 가능한지, SVG 파일을 어디서 불러오는지, 기존 아이콘 컴포넌트와 함께 관리할 수 있는지부터 확인하면 좋겠습니다.
